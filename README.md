AI Data Insights

Upload CSV or Excel files, ask questions in plain English, and get calculated answers, the SQL behind them, KPI summaries, and interactive charts.

The language model only interprets the question and proposes a SQL plan. DuckDB performs every calculation against the uploaded data, so numbers are traceable rather than generated.

Request flow
Step	Component	Action
1	Streamlit	User uploads CSV or Excel files
2	Pandas	Files are loaded into DataFrames
3	DuckDB	Each DataFrame is registered as an in-memory table
4	Catalog	A compact schema description is built
5	GPT-OSS 20B	The question is converted into a structured SQL plan
6	Guardrails	The plan is validated and unsafe SQL is rejected
7	DuckDB	The query executes and the result is calculated
8	App logic	Summary, KPIs, chart, and downloadable result are produced
Design rationale

The model is used for language understanding, not arithmetic. Totals, averages, filters, rankings, joins, and trends are computed by DuckDB. This reduces numerical hallucination and makes every result auditable against visible SQL.

Only compact schema metadata is sent to the model — never entire datasets — and sensitive-looking sample columns are redacted before the prompt is built. The model has no direct access to DuckDB, local files, or external systems; it returns a proposed plan that application code validates before execution.

Why GPT-OSS 20B?

An open-weight reasoning model under the Apache 2.0 license, with reliable structured JSON output suited to SQL generation. The 20B variant balances reasoning quality, latency, and hosted inference cost for a prototype.

Getting started
Prerequisites
Python 3.11
Git
A Groq API key
A GitHub account (for deployment)
Windows
bat
git clone https://github.com/SaikiranSoma/Ai-Data-Insights
cd Ai-Data-Insights

py -3.11 -m venv .venv
.venv\Scripts\activate.bat          :: PowerShell: .\.venv\Scripts\Activate.ps1

python --version
where python

The first Python path should point to .venv\Scripts\python.exe.

bat
python -m pip install --upgrade pip

macOS and Linux
bash
git clone https://github.com/SaikiranSoma/Ai-Data-Insights.git
cd Ai-Data-Insights

python3.11 -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -r requirements.txt
mkdir -p .streamlit
Configure the API key

Create .streamlit/secrets.toml:

toml
GROQ_API_KEY = "your-groq-api-key"

Never place the key in Python source. Never commit secrets.toml.

Run
bash
python -m streamlit run app.py

Open http://localhost:8501 if the browser does not open automatically.

Example questions

Single table

How many records are in the orders table?
What is the average order amount?
Show total sales by region from highest to lowest.
Which five products generated the highest sales?
Show monthly sales totals as a trend.
Show orders above 10,000.

Cross file

Join customers and orders and show total order amount by customer.
Which customer states generated the highest total item sales?
Show the top ten product categories by total sales.
Compare average payment value across customer regions.

Cross-file analysis requires a meaningful shared key such as customer_id, order_id, product_id, a date, a location, or a product code. The application asks for clarification when a relationship or metric is ambiguous.

Recommended test data

A small selection from the Olist Brazilian E-Commerce dataset — orders, order items, customers, products, payments, and the product category translation — exercises multi-file upload, joins, grouping, trends, rankings, and visualizations. Keep each file under the 25 MB upload limit.

Visualization rules

Charts are selected by deterministic application logic, never by the model.

Result structure	Output
One-row result	KPI cards
Date and numeric value	Line chart
Category and numeric value	Bar chart
Proportion or contribution question	Pie chart when suitable
Two numeric measures, relationship question	Scatter chart
Numeric distribution question	Histogram
No reliable visual mapping	Result table only

All chart values come from DuckDB query results.

Security and reliability

Controls applied around AI-generated SQL:

Only SELECT and WITH queries are accepted
Multiple statements are rejected
Destructive operations are blocked
External database and local file access is disabled
Queries are checked by DuckDB before execution
Execution is interrupted after the configured timeout
Results are limited to 1,000 rows
Unknown tables returned by the model are rejected
Failed SQL receives exactly one controlled repair attempt
Ambiguous questions trigger a clarification request
Generated SQL stays visible for auditing
Uploaded data is not permanently stored
Data privacy
Uploaded files are processed within the active Streamlit session.
Complete datasets are never included in model prompts.
The model receives table names, column metadata, statistics, and limited sample values.
Columns that appear sensitive are redacted from prompt samples.

Avoid uploading confidential or regulated data to a public demonstration deployment.

Deployment
1. Prepare the repository
bash
python -m pytest -v
git check-ignore .streamlit/secrets.toml
git ls-files .streamlit/secrets.toml     # must return nothing
git status

If a key was ever committed, revoke it in the Groq Console and create a new one.

2. Commit and push
bash
git add .
git commit -m "Prepare AI Data Insights for deployment"
git push origin main

Replace main with the output of git branch --show-current if needed.

3. Create the cloud application
Open Streamlit Community Cloud and sign in with the GitHub account that can access the repository.
Click Create app and select the repository and branch.
Set the entrypoint to app.py.
Under Advanced settings, select Python 3.11.
Add the production secret:
toml
   GROQ_API_KEY = "your-production-groq-api-key"
Click Deploy.
4. Verify
Open the public URL in an incognito window.
Upload a small CSV and verify basic analysis.
Upload related CSVs and verify a cross-file join.
Confirm SQL, summaries, charts, and downloads work.
Confirm destructive SQL requests are rejected.
Confirm no secret appears in the interface or logs.
5. Update the links
